公开 Legacy PvP Assist 中明确新写的 Toggle Sprint、披风选择/同步和 UV 打包组件，以及保留 MPL-2.0 的格挡文件。未授权旧实现不公开。

分类：PvP 辅助/受限源码子集。原本地版本 `1.0.7-mc1.21.1`，运行目标 Minecraft **1.21.1 / Fabric / Java 21**。Mod ID：`legacy_pvp_assist`。
